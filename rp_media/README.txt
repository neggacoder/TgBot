Картинки-реакции для РП-жестов ("отн обнять", "отн поцеловать", "отн кусь",
"отн шлёп", "отн уебать").

Как это работает
================
Когда пара пишет жест (например «отн обнять»), бот показывает фразу и
прикладывает случайную картинку из папки этого жеста, подобранную по полу
пары. Пол берётся из анкеты — команда «.мойпол м» / «.мойпол ж» (или «мой пол м»).

Структура папок
===============
rp_media/
  hugs/    — обнять
  kisses/  — поцеловать / тьмок / чмок
  bites/   — кусь
  spanks/  — шлёп / шлеп / отшлепать
  smacks/  — уебать
    внутри каждой — три папки по составу пары:
      mf/  — парень + девушка
      mm/  — парень + парень
      ff/  — девушка + девушка

Просто положите файлы картинок в нужные папки. Поддерживаются:
  .jpg .jpeg .png .webp .gif
Имена файлов любые. Бот берёт из папки случайный файл.

Если для точной пары (например mm) картинок нет, бот возьмёт из других папок
того же жеста (сначала mf). Если у жеста вообще нет картинок — покажет жест
текстом с ответной реакцией, без фото.

Почему папки пустые
===================
Готовых картинок в репозитории нет: аниме-арт защищён авторским правом, его
нельзя вшивать в проект. Наполните папки своими изображениями (на которые у вас
есть право их использовать) — код подхватит их автоматически, перезапуск не
нужен.
