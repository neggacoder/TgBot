Картинки-реакции для РП-жестов ("отн обнять", "отн поцеловать", "отн кусь",
"отн шлёп", "отн уебать").

Как это работает
================
Когда пара пишет жест (например «отн обнять»), бот показывает фразу и
прикладывает случайную картинку из папки этого жеста, подобранную по полу
пары. Пол берётся из анкеты — команда «.мойпол м» / «.мойпол ж» (или «мой пол м»).

Структура папок
===============
rp_media/
  hugs/    — обнять
  kisses/  — поцеловать / тьмок / чмок
  bites/   — кусь
  spanks/  — шлёп / шлеп / отшлепать
  smacks/  — уебать
    внутри каждой — четыре папки по НАПРАВЛЕНИЮ жеста (кто кому, а не
    просто «кто с кем»):
      mf/  — парень делает девушке
      fm/  — девушка делает парню
      mm/  — парень + парень
      ff/  — девушка + девушка

Просто положите файлы картинок в нужные папки. Поддерживаются:
  .jpg .jpeg .png .webp .gif
Имена файлов любые. Бот берёт из папки случайный файл.

Если в нужной папке картинок нет, бот НЕ берёт из соседней гендерной: чужая
папка — это и есть неверное направление («уебать» с картинкой, где бьют не
того). Он попробует общую корзину жеста (файлы, лежащие прямо в его папке —
одна картинка на всех, направления в ней нет), а если и там пусто, покажет
жест текстом с ответной реакцией, без фото.

По той же причине пара, у которой хоть у одного пол не указан в анкете, идёт
сразу в общую корзину: направление вычислить не из чего, а угадывать его
значит показывать неверное.

Почему папки пустые
===================
Готовых картинок в репозитории нет: аниме-арт защищён авторским правом, его
нельзя вшивать в проект. Наполните папки своими изображениями (на которые у вас
есть право их использовать) — код подхватит их автоматически, перезапуск не
нужен.
